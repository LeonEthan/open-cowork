# open-cowork

本地 cowork 桌面软件：Typora 美学 × Codex 体验，以外部 AI agent（claude code / codex / pi / opencode…）为 runtime，支持任意 provider 的自由 model 配置。

规划已完成，见 [Wayfinder 地图](https://github.com/LeonEthan/open-cowork/issues/1)。
