# open-cowork 设计宪法

> 地位：一切 UI 实现的最高准则。issue/PR 可直接引用本文件条款（如「违反 §3.2」）。
> 来源：布局骨架以 **Codex 桌面端** 为准——ticket #32 起由「三栏借鉴」升级为**完整对齐**（窗口 chrome 归零、侧栏信息架构、composer 悬浮卡片、空态）；视觉语言取自 **Typora 官方默认主题**（[typora-default-themes](https://github.com/typora/typora-default-themes)，浅色=github，深色=night）。
> 对应票：#9 原型：Typora 风格界面设计稿；#32 宪法修订——Codex 布局全对齐立法。

## §1 布局（Codex 骨架，完整对齐）

### §1.1 窗口 chrome 归零

- **自定义顶栏移除**：顶栏组件整体废除，不渲染任何窗口级横条；macOS 红绿灯经 `titleBarStyle: 'hiddenInset'` 嵌入侧栏顶部区域，侧栏顶端预留红绿灯安全区。
- 顶栏原有职责的归宿：**侧栏折叠开关居内容区左上**（小图标，点击切换侧栏，不占栏位）；**主题切换移入设置**（§1.3 底部设置行为其入口）。

### §1.2 三栏 + 底部终端抽屉（Codex 对齐改造 2026-08 修订，附录 B）

- 任务侧栏（240px，可折叠）｜会话文档流（居中，内容栏 max-width 860px）｜检查栏（320px，变更单栏）｜**底部终端抽屉**（横贯内容区+检查栏下方）。
- 检查栏 = 变更单栏：文件维度复查与 git 操作行（分支 / Commit or push / Compare branch）并入其内；多 tab 架构退场（终端迁出后仅剩变更，tab 条不再渲染）。
- 检查栏**上下文化出现**：选中任务已有变更时自动出现；无可展示内容时不占位——不渲染空槽位、不留 320px 空白；出现/收起走 §5 抽屉 slide。手动唤起开关例外（ticket #34/#37）：内容区右上角常驻小图标开关（⌘J），空态下点击可强制展开并记忆偏好（附录 A）。
- **终端抽屉**（附录 B）：tab 条 = 当前上下文的存活会话 tab（per task / global）+ 新建（+）+ 关闭（✕ 隐藏抽屉）；⌘T 手动唤起/隐藏并记忆偏好；上下文派生沿用 ticket #38 活性定义——当前上下文（选中 taskId，否则 `global`）存在存活 pty 会话时自动出现，失效路径不变（shell 退出 / pty dispose / 应用重启，活性瞬态不落盘）；顶边拖拽调高，高度记忆。
- 文档流是主角：其余栏位默认克制，焦点永远在中间。

### §1.3 侧栏信息架构（自上而下五段；Codex 对齐改造 2026-08 修订，附录 B）

0. **品牌行**：字标（左）+ 搜索 icon + 通知 icon（右）；搜索 = 任务树就地过滤输入；通知 = 待审批/待复查聚合弹层（本地待办，非云端推送，有未读时点亮状态点）。
1. **功能行**：New task 等入口，icon + 文字行，无多余分组装饰。
2. **任务树**：顶部为「置顶」分组（二期 Pinned，附录 A；pinned 任务从原 workspace 分组升入，不重复出现，元信息补 workspace 名；无置顶任务时整组不渲染）；其下按 workspace 分组——workspace 行可展开/收起，任务缩进列于其下；workspace 行本体可选中（选中 = `--bg-pill` 背景 pill + 展开其任务列表 + 首页 hero 跟随该 workspace），展开且无任务时显示「暂无会话」占位；任务行 = 状态点（运行/待批/待复查/完成）+ 标题 + 元信息，无多余装饰。置顶开关为任务行 hover 露出的 icon 按钮，pinned 态常显。
3. **Recents 分组**：跨 workspace 最近任务平铺（按更新时间倒序，默认 5 条 + 「显示更多」），行 = 状态点 + 标题 + workspace 名元信息。
4. **底部设置行**：设置入口（含主题切换）锚定侧栏底部，与上方内容视觉分隔。

- 侧栏无右边线，以 `--bg-soft` 底色与文档区分层；行选中/hover 样式见 §4 侧栏行约定。

## §2 色彩（Typora token 直采）

### 浅色（github 主题）

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#ffffff` | 文档底色 |
| `--bg-soft` | `#fafafa` | 侧栏/ sunk 面（Typora `--side-bar-bg-color`） |
| `--ink` | `#333333` | 正文 |
| `--ink-2` | `#777777` | 次级（Typora `--control-text-color`） |
| `--accent` | `#4183C4` | 链接/运行态/交互焦点（Typora github 主题链接色） |

### 深色（night 主题）

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#363B40` | 文档底色（Typora `--bg-color`） |
| `--bg-soft` | `#2E3033` | 侧栏（Typora night 侧栏色） |
| `--ink` | `#b8bfc6` | 正文（Typora night `--text-color`） |
| `--accent` | `#6dc1e7` | 焦点（Typora night `--primary-color`） |
| 选中 | `#4a89dc` | 文本选中 |

### 语义色（白名单制，除此之外不得引入彩色）

- 成功/批准 `#16a34a`（深色 `#22c55e`）；待批/警告 `#d97706`（深色 `#f59e0b`）；拒绝/错误 `#dc2626`（深色 `#ef4444`）。
- diff：`+` 绿、`-` 红、上下文灰，仅此而已。

#### 任务状态点色谱（2026-08 审计立法，附录 B）

七态与色 token 的映射逐态锁定，新状态入表才许引色：

| 状态 | 色 | 语义 |
|---|---|---|
| `running` | accent + pulse（§5 特许） | 进行中——accent 的唯一动态用途 |
| `awaiting_approval` | 警告橙 | **阻断式待办**：fail-closed 链路暂停，不裁决不继续（催促级） |
| `awaiting_review` | accent（静态） | **非阻断待办**：已完工等人验收，不催促（信息级） |
| `done` | 成功绿 | 变更已验收/无变更完结 |
| `failed` | 错误红 | 失败 |
| `ready` / `cancelled` | ink-3 灰 | 静止态，不占彩色 |

两级「等待人」的区分原则：**橙 = 系统停着等你，蓝 = 系统做完了等你**。
accent 在本表外仍仅限焦点/链接（#37 终审裁决不变）；本表是它的全部特许用途。

### 派生 token（由白名单色 color-mix 派生，不引入新色值）

- `--border` / `--ink-3` / `--selection`：既有派生（定义见 tokens.css），用途不变。
- `--bg-pill`（**选中态背景 pill**，ticket #32 新增）：浅色 = `color-mix(in srgb, var(--ink) 6%, var(--bg-soft))`；深色 = `color-mix(in srgb, var(--ink) 10%, var(--bg-soft))`。**仅限**侧栏 workspace 行/任务行的选中底（hover 取同系减半浓度），不得挪作他用。

## §3 字体与排版

- 正文字体栈（Typora github 主题同款）：`"Open Sans","Clear Sans","Helvetica Neue",Helvetica,Arial,"PingFang SC",sans-serif`。
- 等宽：`"SF Mono","JetBrains Mono",ui-monospace,monospace`。
- 基准 16px，行高 1.6；UI 辅文 13–14px；文档标题 24px/650。
- 用户消息 15px，**右对齐灰 pill**（Codex 对齐改造 2026-08，附录 B：`--bg-soft` 底 + 1px 边框 + 12px 圆角，max-width 约 70%，与 assistant 文档流左右分轨）；元信息/徽标 10.5–12.5px（任务元信息、工具行、用量灰字、计数徽标）——第四档是 §7.4 信息密度约定的具名化，新组件引用字号须落在以上档位内。
- 内容栏 max-width 860px（Typora `#write`），水平留白 ≥30px，文档流底部留白 ≥100px。
- **Composer 宽度独立约定**：约 760px，底部居中悬浮于窗口（不随内容栏 860px 伸缩，不占文档流槽位），与文档流以边框分层。
- 圆角四档：8px / 12px / 16px / 9999px（pill）。**16px 档仅 composer 悬浮卡片与 starter 卡片使用**，其余组件限 8/12/pill 三档。**零阴影**——浮层（命令面板、切换器除外）一律用边框而非阴影分层。

## §4 组件规则

- **工具调用**：极简行（icon + 名称 + 目标 + 状态），详见 #8 决议；不得渲染成大卡片。
- **思考过程**：左边线 + 折叠（`<details>` 式），摘要一行小字。
- **审批托盘**：composer 上方，逐条聚焦，⌘1/2/3（#8 定稿）。
- **代码块**：`--bg-soft` 底 + 1px 边框 + 8px 圆角；语法高亮仅用 ink/ink-3/accent/语义绿四色。
- **Composer（输入区）卡片化**：底部居中悬浮卡片（宽度 760px、圆角 16px，§3 约定），自上而下三行结构——**上下文行**（workspace / 环境 / 分支 chip 等）→ **输入区**（多行文本）→ **动作行**（权限档位 chip、context 水位环、发送键）；边框分层（§3 零阴影），聚焦仅边框变深，无光晕。
- **权限档位 chip 弹层**（Codex 对齐改造 2026-08，附录 B）：点击展开 radio 弹层——三档各一行（档位名 + 一句语义说明），当前档带选中标记；Esc/点击外部关闭。三档语义不变（附录 A 保留差异化），仅交互形式对齐 Codex。
- **Starter 卡片**：文档流空态引导件（hero 问句之下，建议起手任务卡片），16px 圆角 + 1px `--border` 边框；定性为**功能件**，不属 §7.2 装饰禁区。
- **侧栏行约定**：workspace 行/任务行选中 = `--bg-pill` 背景 pill（圆角取 8px 档，行内左右留 6–8px 内边距成 pill 形）；**无描边**；hover 用同系减半浓度底色。

## §5 动效（克制）

- 只许三类：状态点 pulse（1.2–1.6s）、抽屉/折叠 slide（≤220ms ease）、流式光标 blink（1s steps）。
- 禁止：页面级转场、弹性动画、hover 位移。

## §6 主题

- 明暗双主题，默认跟随系统，手动切换记忆偏好；切换无过渡动画（瞬间切换，Typora 同款）。切换入口在侧栏底部设置行（§1.1）。
- 新组件必须同时交付两套主题值，只允许引用 token，禁止硬编码色值。

## §7 禁区

1. 不得引入白名单外的颜色、阴影、第五种圆角（16px 档仅限 §3 指定的 composer 悬浮卡片与 starter 卡片）。
2. 不得在文档流中插入营销性/装饰性元素（插画、渐变、徽章墙）；卡片合法性以 §4 定性为准——composer 悬浮卡片与 starter 卡片为功能件，不在禁列。
3. 不得恢复自定义顶栏或新增任何窗口级 chrome；折叠开关、主题切换等全局控件的归宿以 §1.1 为准。
4. 不得为「好看」牺牲信息密度已有约定（工具行、托盘）；新组件先提 design issue 引用本文件。

## 附录 B：Codex 交互对齐改造记录（2026-08）

以 Codex 桌面端四张基准截图（空态首页 / 会话+分屏预览 / 权限弹层+Environment 面板 / 底部终端抽屉）为准的第二轮对齐。

### 视觉复核（第二轮，以 Codex 原图逐区比对后修订）

- **侧栏顶 strip**：toggle + ‹ › 上移与红绿灯同行（Codex 布局）；侧栏折叠时按钮组退回内容区左上角（§1.1 原约定，两处互斥渲染、testid 唯一）。
- **分组小灰标签**：置顶 / 项目 / 最近 = 12px `--ink-2` 常规字重标签（取代 chevron 装饰行）；workspace 行无 chevron，单击 = 选中 + 折叠切换。
- **空态 hero**：rosette 徽章 + 终端字形（`--ink-3` 单色线稿）；问句 28px/500（§3 字号档位豁免，仅此一处），workspace 名带虚线下划线。
- **starter 卡片**：横排网格（auto-fit），icon 左上 + 单行标签，无 hint 副文；卡片 icon 维持单色（Codex 的彩色 icon 违反 §2 白名单，有意不对齐）。
- **composer 上下文行 = 分段条**：`--bg-soft` 顶条 + 下沿发线，项 = icon + 文字无边框；动作行权限档/模型选择去边框化（纯文字钮）。
- **发送/停止键圆形化**：`--ink` 底 + `--bg` 字形（↑ 发送 / ■ 停止），语义文字入 title。

### 本轮对齐项

- **侧栏 IA 五段**（§1.3）：品牌行（字标 + 搜索过滤 + 待办通知）→ 功能行 → 任务树（workspace 行可选中）→ Recents → 底部设置行。
- **前进/后退导航**：内容区左上角折叠开关旁增设 ‹ ›（视图历史栈，⌘[ / ⌘]）。
- **权限档位 chip 弹层**（§4）：radio 三档 + 说明文案，取代循环切换。
- **用户消息右对齐 pill**（§3）；assistant 消息 hover 露出的 copy 操作行（反馈 👍/👎 与分享不做——本地无反馈回路）。
- **composer 上下文行分支 chip**：git workspace 显示当前分支；非 git 不渲染。
- **starter 卡片补 icon**（currentColor SVG，白名单色）。
- **按轮工作摘要**（P1）：文档流按轮分组——工具/思考/审批行折叠进「工作中 …/已工作 …」摘要行（活跃轮秒级计时 + pulse 状态点；尾注任务级 diffstat「N 个文件 +x −y」；展开体首行聚合小字）；**默认全部展开**（有意偏离 Codex 完成轮默认折叠——复查信息密度优先），用户可手动折叠。
- **会话标题行**（P1）：标题 + 状态行（左）｜「Open in ⌄」（本地等价物：在 Finder 显示 / 在默认应用打开）+「…」菜单（重命名内联编辑 / 置顶切换 / 删除两步确认）（右）。
- **检查栏变更 tab git 操作**（P1）：分支行（当前分支 + upstream 超前/落后）+ Commit or push + Compare branch（worktree 任务对 pin 的 base SHA）。
- **终端迁出为底部抽屉**（P2，§1.2 已修订）：检查栏收窄为变更单栏（tab 条退场）；抽屉 tab 条 = 上下文存活会话 + 新建 + 关闭，⌘T 手动唤起并记忆，顶边拖拽调高；ticket #38 活性定义不变，仅 UI 归属从检查栏 tab 迁至抽屉。

### 维持不做（与附录 A 一致，本轮复核确认）

- 语音按钮、账户区/登录态；Pull requests / Sites / Scheduled / Plugins（云端概念）。
- 产物卡片 + 分屏预览（Open in）：需产物识别协议设计，远期立项。
- composer 附件（+）：需四家 driver 输入协议盘点，远期立项。

## 附录 A：与 Codex 桌面端的对齐记录（ticket #32）

### 有意不对齐项（云端/账户概念，本地优先红线下无对应物，不引入）

- **Pull requests / Sites / Scheduled** 功能行：均为 Codex 云端概念，本地优先架构无对应物。
- **语音按钮、账户区/登录态**：无账户系统（PRD §8 明确不做），不引入任何账户相关 UI。

### 保留差异化（本产物品格，不因对齐而削弱）

- **审批托盘**（fail-closed、逐条聚焦、⌘1/2/3）与**权限三档**（只读/自动/完全放权）——Codex 的「Approve for me」不等价，不照搬。
- **多 agent**（Claude Code / Codex / opencode / pi + 自定义 ACP）与**多 provider 自由配置**——不锁定单一 runtime。
- **检查栏手动唤起开关常驻**（ticket #34 决议，ticket #37 终审登记）：§1.2「无可展示内容时不占位」仅约束栏本体自动规则（不渲染空槽位、不留 320px 空白）；内容区右上角小图标开关（⌘J）空态亦常驻，作为手动唤起/隐藏入口并记忆偏好。此为对本法 §1.2 原条文「不显示其折叠开关」的有意偏离，条文已同步修订。

### 二期落地记录

- **Pinned 置顶任务**（原延期项，已落地）：tasks 表 pinned 列（迁移 008）+ 侧栏任务树顶部「置顶」分组（§1.3）+ 任务行 hover 置顶开关。
